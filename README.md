<h3>Setup Environment Variables</h3>

<p>Create a <code>.env</code> file inside the Backend folder and add:</p>

<pre>
JWT_SECRET="your jwt secret"
STRIPE_SECRET_KEY="your stripe key secret"
MONGODB_URI="your mongodb url"
EMAIL_USER="your email"
EMAIL_PASS="your app password created by gmail"
</pre>

<h3>Run the Project</h3>

<pre>
# Run backend
cd Backend
npm run server

# Run frontend
cd Frontend
npm run dev

# Run admin panel
cd Admin
npm run dev
</pre>
